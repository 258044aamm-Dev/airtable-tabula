# Contributing to Airtable Tabula

Thanks for contributing.

## Maintainer

- [@MehulG](https://github.com/MehulG)

## How to contribute

1. Fork the repo (or use a branch if you have write access).
2. Create a feature branch from `main`.
3. Make your changes and open a **pull request** into `main`.
4. Wait for review. Stale approvals are dismissed when new commits are pushed.
5. Resolve all review conversations before merge.

## Branch protection

`main` is protected:

- No force-pushes or branch deletion
- Changes merge via PR only (squash or rebase)
- At least **1 approving review**, including a **code owner** review
- Linear history required

Repository admins can bypass these rules when needed for releases or hotfixes.

## Release notes for contributors

Do not bump `manifest.json` version or cut GitHub releases unless you are coordinating with the maintainer.
